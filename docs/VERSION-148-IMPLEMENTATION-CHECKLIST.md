# نسخه ۱۴۸ — چک‌لیست پیاده‌سازی و پذیرش

## وضعیت شروع
- [ ] اجرای ۱۴۷: پایان کامل job شبیه‌ساز و ثبت نتیجه نصب/بازشدن؛ در بررسی قبلی job ساخت موفق و job شبیه‌ساز هنوز in_progress بود.
- [ ] APK نسخه ۱.۰.۲۰ / کد ۲۱ روی گوشی واقعی نصب و باز شود.
- [ ] امضای APK نسخه نصب‌شده قبلی با APK جدید مقایسه شود؛ حذف برنامه برای دور زدن خطا ممنوع.

## P0 — یکپارچگی داده و عملیات اصلی
- [ ] فهرست پنج نوع خودرو در UI، اعتبارسنجی کلاینت، Edge Function، RPC و constraintها یکسان باشد.
- [ ] انتخاب چند نوع خودرو و چند مقصد برای راننده با schema فعلی سازگار شود.
- [ ] مبدأ بار فقط تهران باشد و از کلاینت قابل دستکاری نباشد؛ اعتبارسنجی سمت سرور.
- [ ] ثبت گروهی بدون سقف پنج‌قلم، چند مقصد و انواع بار؛ تست تراکنش/خطای جزئی و جلوگیری از ثبت تکراری.
- [ ] تطبیق بار با تمام خودروها و مقصدهای راننده و پذیرش اتمیک بار؛ تست رقابت دو راننده.

## P1 — پروفایل و تنظیمات
- [ ] نمایش و ویرایش نام و نام خانوادگی و فیلدهای مجاز هر نقش.
- [ ] عکس پروفایل با محدودیت نوع/حجم، Storage خصوصی در صورت نیاز و سیاست دسترسی.
- [ ] تنظیم اعلان‌ها، حریم خصوصی، تغییر رمز، راهنما و خروج امن.
- [ ] همه تاریخ‌ها شمسی و زمان رویدادها مبتنی بر زمان سرور با منطقه تهران.

## P1 — پنل مدیریت و امنیت
- [ ] تأیید/رد/مسدودسازی/رفع مسدودی با مجوز سمت سرور و ثبت audit.
- [ ] تعلیق زمان‌دار و دلیل اقدام؛ جلوگیری از ارتقای نقش توسط user metadata.
- [ ] بررسی RLS برای تمام جدول‌های public، سیاست‌های Storage و مجوز EXECUTE توابع.
- [ ] بازبینی همه SECURITY DEFINERها، search_path ثابت، بررسی auth.uid و revoke از PUBLIC در موارد لازم.
- [ ] تأیید تنظیم leaked-password protection در داشبورد و آزمون امن؛ هیچ secret در APK.
- [ ] هیچ جدول یا داده‌ای حذف یا بازسازی نشود.

## P2 — پیام‌رسان
- [ ] مدل گفتگو و عضویت با کنترل نقش‌ها؛ شرکت‌ها و مدیران مجاز در اتاق عمومی.
- [ ] راننده در اتاق عمومی به‌طور پیش‌فرض غیرفعال؛ فقط با مجوز مدیر و حالت read-only.
- [ ] گفتگوی خصوصی با محرمانگی شرکت↔مدیر، شرکت↔شرکت و راننده↔مدیر طبق سیاست مصوب.
- [ ] ارسال متن، تصویر و PDF مجاز؛ محدودیت حجم/نوع و کنترل مدیر.
- [ ] Realtime، وضعیت خوانده‌شدن، صفحه‌بندی و مدیریت خطای اتصال.
- [ ] پیام صوتی: مجوز میکروفون، ضبط، توقف، پیش‌شنوی، ارسال، پخش و مدت‌زمان.
- [ ] mute، حذف/مدیریت پیام و audit برای مدیر ارشد.

## P2 — تماس زنده
- [ ] انتخاب و اتصال سرویس تماس صوتی/تصویری؛ کلیدهای محرمانه فقط سمت سرور.
- [ ] اعلان تماس ورودی، پاسخ/رد، پایان تماس و مدیریت قطع شبکه.
- [ ] مجوزهای runtime میکروفون/دوربین و توضیح روشن به کاربر.
- [ ] محدودیت تماس بر اساس نقش و عضویت گفتگو؛ تست دو دستگاه واقعی.
