## امکانات موجود در سورس (نیازمند آزمون انتها‌به‌انتها)
- نقش‌های راننده، شرکت باربری و مدیر ارشد.
- ثبت‌نام راننده و شرکت با Edge Function موجود `device-register`.
- ورود کاربران با Edge Function موجود `username-auth-v2`؛ ورود موبایلی/SMS هنوز نیازمند تکمیل هماهنگ سمت سرور است.
- ورود مدیر و کنترل نقش‌ها از مسیرهای مدیریتی موجود.
- ذخیره refresh token با Android Keystore و بازیابی نشست.
- ثبت گروهی بار از تهران، نمایش بارها و جست‌وجوی راننده.
- تصویر پروفایل و بارگذاری مدارک.
- گفتگوی خصوصی متنی و پیام صوتی اولیه با RLS و فضای ذخیره‌سازی موجود.

## مواردی که باید به‌صورت واقعی تکمیل و آزمایش شوند
- ورود ساده با شماره موبایل و بازیابی حساب، بدون ساخت حساب تکراری یا از دست رفتن حساب‌های فعلی.
- پذیرش/رد بار و چرخه وضعیت بار با کنترل سمت سرور.
- پنل مدیر ارشد و مدیران: تأیید/رد/تعلیق کاربران، مدیریت نقش و مجوزها، گزارش‌ها و ثبت رویدادها.
- اتاق عمومی با مجوزهای تفکیک‌شده؛ شرکت‌ها امکان ارسال متن/تصویر طبق مجوز، راننده فقط در صورت اجازه مدیر حالت فقط‌خواندنی.
- گفتگوهای خصوصی شرکت↔مدیر، شرکت↔شرکت و راننده↔مدیر طبق نقش و RLS.
- اعلان‌ها، تماس صوتی و تصویری زنده. این تماس‌ها به سرویس signaling/RTC و سیاست‌های سرور نیاز دارند و در APK فعلی آماده و تأییدشده نیستند.
- بررسی همه Edge Functionها، RPCها، جدول‌ها، Storage و RLS با پروژه Supabase موجود.
- تست نصب واقعی روی گوشی Android و آزمون نقش‌ها و نشست‌ها.

## امنیت و حفاظت داده
- هیچ کلید service_role یا راز مدیریتی نباید داخل APK یا سورس قرار گیرد.
- مجوزها باید سمت سرور و با RLS اعمال شوند؛ پنهان‌کردن دکمه در UI کافی نیست.
- هیچ جدول، حساب یا داده‌ای در Supabase بدون بررسی و تأیید صریح حذف یا بازسازی نشود.
- مخزن باید تا پایان ساخت خصوصی بماند؛ وضعیت دسترسی مخزن باید جداگانه بررسی و اصلاح شود.
- این نسخه آزمایشی است و تا پایان آزمون واقعی، آماده انتشار عمومی نیست.
