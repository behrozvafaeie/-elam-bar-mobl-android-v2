# اعلام بار مبل — Android

پروژه بومی Android با Kotlin و Jetpack Compose.

## وضعیت
این مخزن دارای ساختار اولیه قابل ساخت اندروید و گردش‌کار GitHub Actions برای تولید APK آزمایشی است. صفحه ورود/ثبت‌نام فعلاً رابط اولیه است و هنوز به Supabase متصل نشده؛ بنابراین برای استفاده عملیاتی یا انتشار عمومی آماده نیست.

## ساخت
گردش‌کار **Android APK** را در GitHub Actions اجرا کنید. خروجی آزمایشی به‌صورت Artifact با نام `elam-bar-mobl-debug-apk` بارگذاری می‌شود.

## امنیت
- هیچ کلید service_role یا رمز عبوری در سورس قرار ندهید.
- کلید publishable/anon به‌تنهایی مجوز دسترسی به داده‌ها نیست؛ سیاست‌های RLS باید دسترسی را محدود کنند.
- اتصال احراز هویت و داده‌ها فقط پس از بررسی تنظیمات Auth و RLS پروژه موجود اضافه خواهد شد.
