# اعلام بار مبلمان — Android

برنامه بومی Android با Kotlin و Jetpack Compose. نام رسمی برنامه «اعلام بار مبلمان» است و خروجی موردنظر فقط APK اندروید است.

## مبنای توسعه
این شاخه از commit موفق شماره ۲۴۴ ساخته شده و نسخه پایه آن بدون تغییر نگهداری شده است. تمام اصلاحات بعدی روی همین شاخه انجام می‌شود:
- Branch: `release/base-244-preserved`
- Base commit: `a7fcc817036988febf27d5d41d91bb7de733abd1`

## وضعیت فعلی سورس
مواردی که در کد فعلی پیاده‌سازی اولیه دارند:
- رابط فارسی و راست‌چین و انتخاب نقش راننده، شرکت و مدیر ارشد
- ثبت‌نام راننده و شرکت از طریق Edge Function با نام `device-register`
- ورود مدیر ارشد از Supabase Auth و بررسی نقش
- نگهداری refresh token روی دستگاه با Android Keystore
- بارگذاری مدارک راننده و تصویر پروفایل
- فرم افزودن چند بار و ارسال گروهی از مبدأ تهران
- نمایش فهرست بارها و جست‌وجوی رانندگان

## محدودیت‌های شناخته‌شده و کارهای باقی‌مانده
- ورود حساب‌های قبلی راننده و شرکت باید تکمیل و با روش ثبت‌نام هماهنگ شود.
- عملیات مدیریتی تأیید، رد، تعلیق و مدیریت نقش‌ها باید با کنترل دسترسی سمت سرور تکمیل و آزمایش شوند.
- گفتگوی متنی و پیام صوتی اولیه به RLS و Storage موجود وابسته است.
- اتاق عمومی، پیام خصوصی شرکت↔مدیر و شرکت↔شرکت، کنترل مجوزهای ارتباطی مدیر ارشد، اعلان کامل و تماس صوتی/تصویری هنوز تکمیل نشده‌اند.
- تمام Edge Functionها، RPCها، جدول‌ها، Storage و سیاست‌های RLS باید با پروژه Supabase موجود تطبیق داده شوند.
- پیش از انتشار، نصب و اجرای واقعی روی گوشی و سناریوهای اصلی آزمایش شوند.

## امنیت
- کلید `service_role`، رمز عبور یا کلید خصوصی در سورس یا APK قرار نگیرد.
- کلید publishable فقط برای شناسایی پروژه است؛ مجوز دسترسی را RLS و توابع امن سمت سرور تعیین می‌کنند.
- هیچ جدول یا داده‌ای در Supabase بدون بررسی و تأیید صریح حذف یا بازسازی نشود.
- این APK تا پایان آزمون ورود، نقش‌ها، RLS و عملیات اصلی برای انتشار عمومی آماده نیست.
