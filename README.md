# اعلام بار مبلمان — Android

برنامه بومی Android با Kotlin و Jetpack Compose؛ خروجی موردنظر فقط APK اندروید است.

## شاخه توسعه تجمیعی
- Branch: `integration/full-platform-upgrade`
- Base: `release/base-244-preserved`
- نسخه‌های ۲۴۴، ۲۶۰ و ۲۶۱ محفوظ هستند و این شاخه مستقل از آن‌ها توسعه می‌یابد.

## امکاناتی که در سورس فعلی وجود دارند
- رابط فارسی و نقش‌های راننده، شرکت باربری و مدیر ارشد
- ثبت‌نام راننده و شرکت از طریق Edge Function با نام `username-auth-v2`
- ورود کاربران با نام کاربری و رمز عبور؛ ورود مدیر از Supabase Auth
- نگهداری refresh token در Android Keystore و بازیابی نشست
- بارگذاری تصویر پروفایل و مدارک راننده
- فرم ثبت گروهی بار از مبدأ تهران
- فهرست بارها، جست‌وجوی رانندگان و بخش‌هایی از مدیریت مدیران
- گفتگوی متنی و ضبط، ارسال و پخش پیام صوتی برای گفتگوهای مجاز تخصیص بار

## مواردی که هنوز کامل نیستند یا باید با سرور آزمایش شوند
- ورود با شماره موبایل به‌جای نام کاربری، بدون تغییر حساب‌های موجود
- عملیات کامل و امن مدیر ارشد: تأیید/رد/تعلیق حساب، مدارک، بارها، نقش مدیران و ثبت رویدادها
- پذیرش و رد بار از سمت راننده، با ثبت وضعیت قابل اتکا در سرور
- اتاق عمومی و پیام خصوصی شرکت↔مدیر و شرکت↔شرکت با مجوزهای دقیق
- اعلان‌های قابل اتکا
- تماس صوتی و تصویری زنده؛ این قابلیت‌ها به سرویس تماس/زیرساخت signaling و تنظیمات سرور نیاز دارند و هنوز در این نسخه پیاده‌سازی نشده‌اند.
- بررسی همه Edge Functionها، RPCها، Storage و RLS در پروژه Supabase موجود

## ساخت
- Application ID: `ir.elambar.mobl`

- minSdk: 24، targetSdk: 35
- خروجی: Debug APK برای آزمون

## امنیت و انتشار
- کلید service_role یا رمزهای مدیریتی هرگز در APK قرار نگیرند.
- دسترسی‌ها باید با نشست کاربر و RLS سمت سرور کنترل شوند.
- هیچ جدول یا داده‌ای در Supabase بدون بررسی و تأیید صریح حذف یا بازسازی نشود.
- این نسخه تا پایان آزمون نصب واقعی، احراز هویت، نقش‌ها، RLS و عملیات اصلی برای انتشار عمومی آماده نیست.
- مخزن باید پیش از انتشار عمومی خصوصی شود؛ وضعیت فعلی مخزن باید در تنظیمات GitHub اصلاح شود.
